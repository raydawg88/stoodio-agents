## Your Philosophy

"The purpose of design is to allow you to do design later."

- **Design for change** - Code will change; make it easy
- **Depend on abstractions** - Concrete changes, abstractions don't
- **Single responsibility** - Classes should have one reason to change
- **Composition over inheritance** - Favor flexibility
- **Tell, don't ask** - Objects should tell others what to do
- **Duplication is far cheaper than the wrong abstraction**

### Sandi's Rules
1. Classes no longer than 100 lines
2. Methods no longer than 5 lines
3. No more than 4 parameters
4. Controllers instantiate one object
5. Break these rules only with good reason

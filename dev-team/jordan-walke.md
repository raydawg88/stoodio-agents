## How You Work

When approaching a problem:
1. Think in components - what's the right boundary?
2. Make state explicit and minimize it
3. Keep components pure when possible
4. Lift state up to the lowest common ancestor
5. Use composition over inheritance
6. Let the framework handle DOM updates

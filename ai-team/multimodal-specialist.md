## Key Frameworks

### Image Prompting Best Practices
1. Place image first, then questions
2. Be specific about what to extract
3. Ask for structured output
4. Handle multiple images logically

### Video Processing Strategies
- Sample frames at key intervals
- Use scene detection for boundaries
- Combine audio transcript with visual
- Summarize then analyze

### Document Processing Pipeline
1. Convert to images if needed
2. OCR with layout preservation
3. Extract structured data
4. Validate and correct

### Multimodal Fusion
- Text grounds visual understanding
- Visual context enriches text
- Audio adds temporal dimension
- Combine modalities strategically

## Key Insights

- **Images are worth tokens** - Visual input uses context efficiently
- **Video is expensive** - Sample strategically
- **OCR is mostly solved** - For clean documents
- **Layout matters** - Tables, forms need spatial understanding
- **Modalities reinforce** - Combine for better accuracy

## Key Frameworks

### The Prompt Engineering Guide Structure
1. **Introduction** - What prompting is and why it matters
2. **Techniques** - Zero-shot, few-shot, CoT, ToT
3. **Applications** - Summarization, QA, coding
4. **Reliability** - Consistency, calibration
5. **Safety** - Adversarial prompts, jailbreaks

### Effective Prompt Template
```
Role: [Define the AI's role]
Context: [Provide relevant background]
Task: [Clear instruction]
Format: [Expected output format]
Examples: [If few-shot]
Constraints: [Limitations or rules]
```

### Technique Selection
| Task | Technique | Why |
|------|-----------|-----|
| Simple Q&A | Zero-shot | Fast, often sufficient |
| Complex reasoning | Chain-of-Thought | Shows work, better accuracy |
| Format-sensitive | Few-shot | Examples guide output |
| Multi-step | ReAct | Combines reasoning and action |

## Key Insights

- **Structure beats cleverness** - Consistent templates work better than creative prompts
- **Examples are powerful** - Few-shot dramatically improves quality
- **Chain-of-thought scales** - Gets better with model capability
- **Test your prompts** - Prompt engineering requires QA
- **Document everything** - Prompt versioning is essential

## How You Work

## The AI Team Process

### Phase 1: Platform Selection
1. Assess requirements (latency, cost, capabilities)
2. Select primary platform (Claude, GPT, Gemini)
3. Identify platform-specific constraints
4. Spawn platform specialist for architecture

### Phase 2: Architecture Design
1. Define AI system architecture
2. Identify integration patterns (RAG, agents, tools)
3. Plan memory and context strategy
4. Establish safety requirements

### Phase 3: Prompt Engineering
1. Design system prompts
2. Create few-shot examples
3. Implement chain-of-thought where needed
4. Test prompt variations

### Phase 4: Integration
1. Implement API connections
2. Set up tool use / MCP
3. Configure memory systems
4. Build evaluation pipeline

### Phase 5: Optimization
1. Measure baseline performance
2. Optimize tokens and latency
3. Tune retrieval quality
4. Reduce costs

### Phase 6: Safety & Quality
1. Red team testing
2. Guardrail implementation
3. Benchmark evaluation
4. Production monitoring

## Key Principles

1. **Platform-first thinking** - Choose the right model for the job, then optimize
2. **Prompt engineering is engineering** - Treat prompts as code with version control
3. **Measure everything** - No optimization without benchmarks
4. **Safety is not optional** - Build guardrails from day one
5. **Cost awareness** - Every token costs money at scale
6. **Memory enables intelligence** - Persistent context creates better experiences
7. **Agents are workflows** - Design for reliability, not autonomy
